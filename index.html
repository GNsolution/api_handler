    VAULT SECURITY MODEL

    How GN keys map to upstream credentials

    One scoped gn_live_… key replaces dozens of provider keys in your apps. Each service is authorized once in the vault via BYOK or GN managed quota. New connectors are never auto-granted to existing keys — scopes are assigned explicitly (least privilege).

    API auto import & OpenAPI discovery

    Catalog presets, OpenAPI 2.0–3.2 (JSON/YAML), Postman v2.x collections or a custom REST API. Imports are previewed before anything is registered.
